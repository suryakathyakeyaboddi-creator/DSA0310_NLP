NLP CO2 AT1 - Python Programs and IDLE-style Output Previews

Files:
- Q1 to Q5 .py files: runnable Python programs for each assignment question.
- Q1 to Q5 IDLE_Output.png files: IDLE-style screenshots showing the program output.

Run instructions:
1. Open IDLE.
2. Choose File > Open and select a .py file.
3. Press F5 (Run > Run Module).
4. Q5 requires NLTK. Install once in the terminal with: pip install nltk

Note: The PNGs are IDLE-style output previews generated from the program output, not photographs of an actual IDLE window.
